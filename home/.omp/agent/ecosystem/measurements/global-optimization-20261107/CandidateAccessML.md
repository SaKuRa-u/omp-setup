## Kesimpulan

**Pertahankan OMP native dan skill incumbent sebagai dasar; tambahkan kemampuan yang benar-benar baru secara selektif, bukan seluruh paket global.**

Prioritas:
1. **Graphify** untuk graph struktural lokal; **Understand-Anything** sebagai alternatif bila tujuan utama onboarding visual dan pemetaan domain.
2. **Agent Reach** untuk platform khusus/login; untuk kebutuhan YouTube saja, API resmi + **yt-dlp** lebih kecil cakupannya.
3. **Hugging Face skills** untuk pekerjaan ML tertentu.
4. **Spec Kit** sebagai workflow proyek opt-in, bukan kebijakan global.
5. Paket engineering lainnya lebih tepat menjadi sumber pembaruan/komplement skill incumbent daripada dipasang bersamaan secara menyeluruh.

**Status seluruh penilaian: source-assessed, bukan runtime-tested.** Sumber primer: repo upstream, manifest/dependency, release resmi, dan dokumentasi Google. Klaim performa pemasok tidak dianggap bukti independen.

## YouTube resmi versus Agent Reach

**Penting: jangan memakai angka kuota lama dari ingatan. Dokumentasi resmi yang diperiksa sekarang menggunakan bucket search terpisah.**

| Kebutuhan | API resmi | Agent Reach |
|---|---|---|
| Metadata | [`videos.list`](https://developers.google.com/youtube/v3/docs/videos/list): 1 unit/request; snippet, statistics, contentDetails. Bagian file/processing/suggestions hanya pemilik. | yt-dlp `--dump-json --skip-download`; tidak memakai YouTube Data API. |
| Search | [`search.list`](https://developers.google.com/youtube/v3/docs/search/list): **100 calls/hari default**, 1 unit di bucket Search Queries; maksimal 50 hasil/page, pagination setiap request. | `ytsearchN` lewat yt-dlp; tanpa API key/kuota Data API, tetapi tetap bisa terkena rate-limit atau challenge. |
| Upload terbaru suatu channel | Dokumentasi menyarankan uploads playlist + `playlistItems.list`, bukan mengandalkan search index yang bisa terlambat/tidak lengkap. | Bukan keunggulan khusus yang dibuktikan dari backend YouTube yang dibaca. |
| Caption metadata | [`captions.list`](https://developers.google.com/youtube/v3/docs/captions/list): OAuth, 50 unit; **bukan teks caption**. | Subtitle manual/auto diambil yt-dlp dan diubah dari VTT ke teks. |
| Caption download | [`captions.download`](https://developers.google.com/youtube/v3/docs/captions/download): OAuth, **200 unit dan izin mengedit video**. Bukan transcript API universal video publik. | Dapat membaca caption publik yang tersedia tanpa hak edit, tetapi melalui mekanisme non-Data-API yang bisa berubah/diblokir. |
| Tidak ada caption | Data API bukan layanan speech-to-text. | Transcribe audio melalui Groq/OpenAI Whisper; memerlukan ffmpeg/key, waktu dan kemungkinan biaya. |

[Kuota resmi](https://developers.google.com/youtube/v3/determine_quota_cost): 10.000 unit/hari gabungan endpoint lain, default search/upload bucket masing-masing 100 calls/hari; reset midnight Pacific.

**Pilihan aman:** API resmi untuk metadata/search terstruktur dan caption video yang dikelola sendiri; yt-dlp/Reach hanya untuk kebutuhan caption publik yang diizinkan. Challenge bukan alasan otomatis mengimpor cookie atau mencoba menghindari pembatasan. API resmi tidak menggantikan kemampuan transcript publik Reach, dan Reach tidak menjamin stabilitas/otorisasi API resmi.

## Kandidat tambahan yang benar-benar relevan

**[yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26)** — alternatif lebih kecil daripada Agent Reach bila kebutuhan hanya YouTube/video.

- Latest stable yang diperiksa: `2026.10.26`, SHA `f264a6cbd1f630894da0f368df00f8aae50140e0`.
- Python **≥3.11**, binary Windows **Windows 10+**; lisensi utama Unlicense, distribusi membawa lisensi dependency tambahan.
- Tanpa model call wajib; metadata/search/subtitles, ffmpeg untuk operasi media tertentu.
- **Tradeoff:** pengguna mengelola command/error sendiri; tidak mendapat adaptor lintas-platform Reach. Tetap ada risiko anti-bot, cookie, hak cipta dan ketentuan platform.
- Jangan mengganti yt-dlp terpin milik Reach secara sepihak: Reach `v1.6.1` memanggil dependency Python miliknya sendiri, bukan sekadar executable PATH.

Tidak menambah kandidat kedua karena kemampuan lain yang relevan sudah tersedia pada OMP/incumbent atau sebelas repo tersebut.

**Tidak dijalankan:** installer, build/lint/test, model calls, browser login, credential/session reads, maupun service. Risiko tersisa: kompatibilitas Windows/OMP dan biaya aktual belum diuji runtime; seluruh adopsi harus dipin dan dipilih per kebutuhan.
