## Strategi global-sharing yang didukung

**Tidak perlu menonaktifkan profile isolation atau menyatukan seluruh `.omp` untuk berbagi kapabilitas.**

| Yang dibagikan | Mekanisme supported | Batas/tradeoff |
|---|---|---|
| Defaults seluruh proyek dalam satu profile | Active global `agent/config.yml`, native `skills/commands/agents/rules/...`, user-scope plugins. | “Global” ini **profile-global**, bukan otomatis lintas profile. |
| Settings lintas profile | File bersama melalui repeated **`--config <file>`** atau **`PI_CONFIG_FILES`**. | Overlay non-persistent, prioritas di atas project; bagus untuk policy, tetapi project tidak dapat mengoverride array policy tersebut. |
| Skills lintas profile | **`skills.customDirectories`** menunjuk satu pohon bersama `root/<skill>/SKILL.md`. | Non-recursive; custom directories mengungguli default discovery pada collision. Array higher-layer replace. |
| Paket kapabilitas lintas profile | **`extensions: [absolute-package-root]`** atau explicit **`--extension <package-root>`**; paket dapat menyediakan sibling agents/skills/commands/rules/MCP. | Setiap profile/run harus mereferensikannya. Berbagi source tidak menyamakan enable/install/settings state; executable extensions membawa trust besar. |
| Instruksi bersama | File lokal kecil memakai **`@absolute-path` / `@~/...` imports**; `contextFiles.extra` untuk basename tambahan. | Subagents mengecualikan nama `AGENTS.md`; constraints helper sebaiknya ada pada sticky `RULES.md` atau explicit shared brief. Jangan mengimpor rahasia. |
| Settings file shared lewat symlink | Tag mendokumentasikan symlinked main config: save mempertahankan link, reload mengikuti target. | Ini **sharing file**, bukan profile inheritance. Semua penulis memengaruhi target yang sama; Windows path/link permissions perlu diuji parent. |
| Foreign ecosystem config | Opt-in **`enabledProviders: [claude,codex,…]`**; foreign user roots tidak profile-scoped. | Membuka seluruh kapabilitas provider, bukan hanya skill yang diinginkan. Hindari `["*"]` bila tujuan hanya satu direktori skill. |
| Shared credentials | Auth broker merupakan mekanisme resmi terpisah. | Bukan alasan menyatukan `agent.db`/session directories. Di luar pemeriksaan credential assignment ini. |

**Rekomendasi paling kecil:** tetap isolasikan auth/sessions/caches; bagikan hanya overlay policy, skill directory, dan package roots yang memang perlu. Jangan menciptakan asumsi `~/.omp/shared` otomatis ditemukan—tidak ada dasar dokumentasi yang dibaca untuk itu.

## Arsitektur singkat

1. **Settings registry** mendefinisikan key/default/type; layers menentukan nilai efektif.
2. **Capability providers** menemukan context, rules, skills, commands, tools, extension roots; dedup dan precedence **berbeda per subsystem**.
3. **Model registry/auth router** menentukan route/model yang tersedia; roles bukan agent definitions.
4. **Session runtime** mengelola modes, tool approvals, retries, compaction, persistence, advisor, dan task children.
5. **SDK, RPC, ACP, CLI** memakai inti tersebut, tetapi host defaults/UI/MCP/lifecycle tidak identik.

Source utama untuk parent: `config/settings.ts`, `config/registry.ts`, `discovery/*`, `task/{agents,discovery,structured-subagent,executor,settings}.ts`, `slash-commands/builtin-{modes,lifecycle}.ts`, `advisor/*`, dan `modes/acp/acp-agent.ts`. [ACP source: client-managed MCP](https://github.com/can1357/oh-my-pi/blob/b5a6b2f7e5b6606b6562e678ead83f21738f34a0/packages/coding-agent/src/modes/acp/acp-agent.ts#L1744-L1748).

## Saran verifikasi parent

Tanpa membuka credential atau melakukan task model-backed:

- Cocokkan **key spesifik non-secret**, bukan dump config: `task.isolation.enabled`, `isolation.backend`, `task.maxConcurrency`, `task.enableLsp`, `prewalk.into`, `advisor.reviewMode`, `compaction.methodOrder`, `goal.continuationModes`.
- Periksa `omp --help` / `<subcommand> --help` untuk flags build aktual; **jangan ulang pemeriksaan versi yang sudah terverifikasi**.
- Pada UI yang sudah berjalan, `/tools` dan `/agents` dapat membedakan capability registered/mounted, agent custom, dan bundled. Tidak perlu membuka transcript worker.
- Parent dapat menguji reload/isolated revival/prewalk hanya bila memperoleh mandat runtime terpisah. Hasil source di atas **belum membuktikan** platform backend atau endpoint pengguna berfungsi.
- Optimasi awal: fan-out kecil dan file-disjoint; routing exact roles; reuse worker yang relevan; advisor final-only `agent-end` bila setiap tool-round terlalu mahal; jangan langsung mengaktifkan strict backlog, auto upgrades, browser relay, atau computer.

Tidak diperiksa: eksekusi runtime, credential/entitlement, seluruh adapter/backend OS, dan kompatibilitas setiap plugin terpasang.  
Risiko utama: website drift, discovery lintas sumber, dan “isolated/headless/read-approved” yang disalahartikan sebagai sandbox atau larangan efek samping.
