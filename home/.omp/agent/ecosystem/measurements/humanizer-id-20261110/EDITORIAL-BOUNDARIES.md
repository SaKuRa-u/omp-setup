# Batas Humanizer ID pada OMP

Humanizer ID adalah penyunting bahasa Indonesia pendukung. Baca panduan asli saat pengguna meminta penyuntingan/proofreading prosa Indonesia. Bukan default gaya semua jawaban, bukti teks ditulis AI, atau alat lolos detektor. Academic-paper tetap pemilik authoring/revisi akademik; humanizer existing untuk bahasa lain/pola lintas bahasa sesuai kebutuhan; jangan menumpuk dua humanizer untuk satu pass.

Makna naskah, pedoman instansi/venue terkini, instruksi pengguna dan integritas ilmiah menang atas contoh/preset vendor. Pertahankan isi proposisi, angka dengan pembatasnya (sebesar/hingga/sekurang-kurangnya), satuan, rentang, negasi, hubungan sebab/korelasi, perbandingan, atribusi/sitasi, modalitas, persamaan, kode, istilah teknis dan kutipan. Simpan asli; suntingan dan catatan perubahan dipisahkan. Ambiguitas/substansi keliru diberi catatan penulis, bukan diam-diam dilengkapi atau diperkuat.

Tidak ada penggantian kata massal, kuota konjungsi per halaman, pemaksaan pasif/persona atau perajutan sitasi bila merusak atribusi. Contoh memory boundaries tidak boleh menjadi memory capacity bila konteks batas alamat/akses. Diharapkan/diduga tidak menjadi terbukti. Jangan menambahkan kondisi beban penuh, dataset bahasa tertentu, metode, parameter atau hasil yang tidak ada. Instrumen tervalidasi, kutipan, nama dan klausul hukum dilindungi.

Preset kampus adalah referensi belum diverifikasi terhadap setiap fakultas/tahun; nama kampus tidak otomatis mengubah gaya sitasi, margin atau struktur. Pakai pedoman resmi yang disediakan pengguna/venue. Sitasi IEEE numerik jangan diubah ke pengarang-tahun. Rujukan EYD primer mengalahkan ringkasan vendor yang kontradiktif; aturan EYD bukan bukti semua klaim tata bahasa benar. Bila tidak pasti, tandai saran dan pertahankan teks.

Hanya panduan/dokumen/data asli dipasang. Tidak memasang atau menjalankan paket/CLI Python, audit.py, installer, jurnal subskill, PROMPT global, hook, MCP, provider, telemetry atau layanan. Referensi script dalam panduan bukan kapabilitas executable tersedia. Hasil AI perlu review penulis; uji sintetis terbatas bukan sertifikasi kebahasaan atau jaminan preservasi universal.
